# მიკვებე (Mikvebe) - AI შეფი და პერსონალური კლინიკური დიეტოლოგი

სრული Full-Stack ვებ-აპლიკაცია ჯანსაღი კვების, მაცივარში არსებული პროდუქტების ამოცნობის, 1-თვიანი დეტალური კვების გეგმის, წყლის ბალანსის კონტროლისა და პერსონალური პროფილისთვის.

## ძირითადი მოდულები და შესაძლებლობები

1. **AI შეფი & პროდუქტების ფოტო ანალიზი:**
   - მაცივრის ან პროდუქტების ფოტოს ატვირთვა ან ნიმუშის არჩევა.
   - ინგრედიენტების ავტომატური ამოცნობა (Google Gemini AI).
   - კერძების გენერაცია კალორიებით, მაკრონუტრიენტებით (ცილები, ცხიმები, ნახშირწყლები) და მომზადების ეტაპებით.

2. **1-თვიანი (4 კვირიანი) კვების გეგმა:**
   - კლინიკური დიეტოლოგის ალგორითმი: ასაკი, სიმაღლე, წონა, აქტივობის დონე და მიზანი (წონის დაკლება, კუნთოვანი მასა, შენარჩუნება, ჯანსაღი კვება).
   - BMR & TDEE გამოთვლა (Mifflin-St Jeor ფორმულა).
   - დღიური განრიგი ზუსტი საათებით: საუზმე (09:00), წახემსება (12:00), სადილი (15:00), ვახშამი (19:00).
   - სრული და დაჯგუფებული შესაძენი სია (Shopping List) ზუსტი გრამებითა და რაოდენობებით ყოველი კვირისთვის.
   - ექიმის რეკომენდაციები და ოქროს წესები.

3. **წყლის ბალანსის ქრონომეტრი (Water Tracker):**
   - პერსონალური დღიური ნორმის გათვლა წონის მიხედვით.
   - 250 მლ ჭიქების ინტერაქტიული მრიცხველი და ვიზუალური პროგრეს-ბარი.
   - საათობრივი შეხსენებები და რეჟიმის კონტროლი.

4. **მომხმარებლის ანგარიში (User Account & Saved Plans):**
   - უნიკალური იდენტიფიკატორის სისტემა (მაგ. `MIK-XXXXX`).
   - შედგენილი 1-თვიანი კვების გეგმების დამახსოვრება და შენახვა.
   - რეცეპტების რჩეულებში შენახვა.

5. **უკუკავშირის (Feedback) ფორმა:**
   - მოგვწერეთ / უკუკავშირის მოდალი რეიტინგითა და ვალიდაციით.
   - მხარდაჭერილია Web3Forms-ის ინტეგრაცია პირდაპირ ელ.ფოსტაზე გასაგზავნად.

6. **SEO და საძიებო ოპტიმიზაცია:**
   - სრული ქართულენოვანი OpenGraph, Twitter Cards და Schema.org JSON-LD სტრუქტურირებული მეტა-მონაცემები.

## ტექნოლოგიური სტეკი

- **Frontend:** React 19, TypeScript, Tailwind CSS, Lucide React
- **Backend:** Node.js, Express, Vite Middlewares
- **AI ინტეგრაცია:** `@google/genai` (Google Gemini API)

---

## ლოკალურად გაშვება

```bash
# 1. დამოკიდებულებების დაყენება
npm install

# 2. გარემოს ცვლადების კონფიგურაცია (.env)
cp .env.example .env
# ჩაწერეთ თქვენი GEMINI_API_KEY და სურვილისამებრ WEB3FORMS_ACCESS_KEY

# 3. დეველოპერული სერვერის გაშვება
npm run dev
```

პროექტი გაეშვება პორტზე: `http://localhost:3000`
